## driving-risk-metrics v1.0.1

修正版。**沒有任何已發布的量測數字改變**，`docs/evidence/` 底下六份文件與 `docs/claims.yaml`
的 32 條宣稱全部與 v1.0.0 相同，稽核仍為零違規。

### 修正

**選擇性風險曲線的面積會超出它自己文件承諾的範圍。** 這個缺陷由專案自己的 Hypothesis
property test 在提交前的驗證關卡找到，不是靠人眼看出來的：當一條曲線的每個涵蓋點風險都
是最大值時，梯形積分的捨入誤差會讓結果比上界多出兩個 ulp。輸入驗證已經保證風險落在
單位區間、涵蓋率嚴格遞增，所以加權平均在數學上不可能超出該區間，超出的部分可證明純屬
浮點誤差，回傳值因此被夾緊，並在原始碼旁寫明理由。同時補上一個確定性回歸測試釘住兩端，
因為只在 Hypothesis 資料庫覆蓋得到的地方成立的契約，等於沒有被釘住。

這個情形只有在「每一個預測都錯」的退化曲線才會出現，任何真實執行都不會遇到，所以
released 的數值不受影響。它原本會讓公開 repo 的 CI 變得時好時壞，因為全新的 runner
沒有 Hypothesis 資料庫，可能碰到也可能碰不到；現在是確定的。

### 靜態報告

發布的證據網站先前完全沒有樣式表，瀏覽器只能套用預設值。現在補上一份內嵌樣式：深淺
兩種配色、固定行寬、表格框線與置頂表頭、長雜湊自動斷行，每個表格各自水平捲動而不會
讓整頁橫向滾動；圖表放在固定淺色卡片上，因為它們自己畫在淺色畫布並使用深色座標文字。
沒有外部樣式表也沒有網路字型，所以建置仍然是離線且可重現的。
