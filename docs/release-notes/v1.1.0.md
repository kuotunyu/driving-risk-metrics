# v1.1.0 — 兩份預先登記的發布後分析

本版新增兩份發布後分析。兩份都在任何結果出現之前先 commit 分析計畫，結果放在各自獨立的
文件與獨立的 claims 檔，由 claims validator 逐一追溯。v1.0.x 的 evidence、`docs/claims.yaml`、
圖表、protocol、凍結 cohort 與既有 tag／release 都沒有改動。

- **解析度分析**（[結果](../posthoc/resolution-v1/results.md)）：在 calibration split 上，
  不重新訓練、只把推論輸入提高到原生解析度，小尺寸 person 只救回一小部分，而且大尺寸 person
  反而變差。預先登記的整體判定為「部分支持」解析度假說。新增指令
  `driving-risk resolution-sweep parity|run|analyse|evidence`。
- **全 seed 分析**（[結果](../posthoc/allseed-v1/results.md)）：用已發布的 locked cohort 預測，
  補上另外兩個 seed 的 instance 覆蓋率，以及信心類與易受傷害用路人逐類指標的區間。結論是
  seed 17 具代表性，三個模型都漏掉多數最小 tertile 的 person，而且兩兩之間可以區分。新增指令
  `driving-risk allseed extract|analyse|evidence`。

全 seed 分析在讀任何結果之前有兩道關卡：完整性（每個預測檔都必須是其評估紀錄記下的那一份）
與重現（新程式必須逐位元重現它涵蓋到的每一個已發布數字）。兩道都通過。

實驗卡記錄的兩項偏差，現在分別指向回答它們的全 seed 分析；影像分帶的 pixel accuracy
仍然沒有區間。套件版本、`CITATION.cff` 與 lock 中的專案版本統一為 `1.1.0`，依賴版本不變。
