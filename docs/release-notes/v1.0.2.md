# v1.0.2 — 套件版本與建置重現性修正

本版修正發布工程：套件 metadata、lock 與 `drivemetrics.__version__` 統一為
`1.0.2`，並在產生 checksum 前核對預定 tag、已安裝套件、wheel 與 sdist 的名稱
和版本。既有 `v1.0.0`、`v1.0.1` 的 tag 和發布檔案保留原樣。

Release workflow 先檢查 lock 是否仍符合宣告，再使用 Python 3.11 的 frozen
環境建置；setuptools 固定為 84.0.0、wheel 固定為 0.45.1，關閉額外隔離環境
的依賴解析。`SOURCE_DATE_EPOCH` 取自實際 tagged commit 的提交時間並傳入建置。

實際兩次候選建置發現 wheel 已一致，sdist 仍受 gzip 與 TAR/PAX 時間戳影響，
檔案 payload 沒有變動。因此新增固定 archive 時間戳、清空 gzip filename header
的正規化與 payload 保留
測試。`SHA256SUMS` 只列 wheel、sdist 的可攜檔名；發布資產明列這兩類檔案與
checksum，並要求遠端 tag 已存在。

repo 外的共用 clean-clone 工具也已修正：來源路徑必填，branch 預設 `main`，
package 預設 `drivemetrics`；保留完整命令輸出與失敗 exit code，可明確指定
其他專案參數。這個私有 workspace 工具不包含在公開套件中。

驗證方式、候選診斷與正式發布前的同 commit／epoch 雙建置、安裝檢查和遠端
驗收門檻見 [release checklist](../verification/release-checklist.md)。
本版不修改模型、protocol、凍結 cohort、統計方法或既有科學結果。

雙語 README 與 experiment card 同時收斂結果解釋：差值區間包含零不能證明模型等效，
語意分割指標不能直接證明煞車安全；逐 seed 的一致性限於本研究的執行，
不推廣成模型架構的普遍性質。原始數值、claims 綁定與 evidence 檔案保持不變。
